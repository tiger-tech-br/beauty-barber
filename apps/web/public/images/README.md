Caso os arquivos estejam em JPG ou PNG, converta para WebP mantendo o enquadramento antes da integração, ou adapte o caminho CSS ao formato disponível. **Não substitua as fotografias já aprovadas por imagens genéricas.**

O layout tem fundos de segurança caso essas fotos ainda não tenham sido adicionadas. Não há imagens falsas nem downloads externos automáticos.
